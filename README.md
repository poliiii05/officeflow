\# OfficeFlow



OfficeFlow is an office appointment and ticketing system with AI-assisted request management.



\## Tech Stack



\- Laravel

\- React TypeScript

\- PostgreSQL

\- Laravel Sanctum

\- TailwindCSS

\- shadcn/ui

\- Postman

\- Docker and CI/CD later



\## Phase 0



Project foundation setup:

\- GitHub repository

\- PostgreSQL database

\- Laravel backend setup

\- React frontend setup

\- API health check
